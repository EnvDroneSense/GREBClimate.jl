Plots and notebook

The repository ships a plotting toolbox (viz/, module GREBViz) and a Pluto notebook (viz/notebooks/GREB_explorer.jl) built on it. Neither is part of the package: they use their own environment, viz/Project.toml (Plots, Pluto, PlutoUI). Both need the dataset on disk (see Input data); they never download it.

The notebook

From the repository root:

julia viz/notebooks/launch_pluto.jl

This opens Pluto in the browser with the explorer loaded. Each launch brings the viz/ environment up to date; the first takes a few minutes. Pick an experiment and the number of control and scenario years, tick Run the model, then choose a variable. The notebook runs the preset's flux-correction spin-up (3 years for most presets) before the control, shows the plots of the next page, and adds a frame-by-frame view of the run that can be played or exported as a GIF.

From a script

Set up the environment with the command below. The notebook launcher does this on every start, and you should run it again after updating the repository:

julia viz/setup.jl

Then, with julia --project=viz:

include("viz/GREBViz.jl"); using .GREBViz

plot_map(result; var = :Ts, fields = fields)   # fields adds coastlines
plot_timeseries(result; annual = true)

result is what greb_model! returns and fields the climatology from load_climatology. Two commands run the whole toolbox:

julia --project=viz viz/demo.jl [output_dir]   # runs GREB and saves every plot
julia --project=viz viz/test.jl                # the toolbox's tests, no dataset needed
julia --project=viz -t 2,0 viz/docs_figures.jl # regenerates the figures of these pages
